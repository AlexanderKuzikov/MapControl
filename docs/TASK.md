# TASK.md — диспетчер кодовых сессий MapControl

## Постоянная часть (правила, меняет только штаб)

1. Запуск кодовой сессии фразой: «`MapControl. Читай docs/TASK.md`». Сессия идёт по указателю ниже к своему файлу и больше ничего не читает лишнего.
2. Одно задание — одна работа: отдельно сдаётся, отдельно тестируется, отдельно откатывается. «Заодно» не делать.
3. Сессия правит только свой файл задачи (статус, отчёт) и файлы из раздела «Входит». Диспетчер, очередь, архив — только штаб.
4. Жизненный цикл: `открыта → в работе → на проверке → принята`.
5. Отчёт без выводов команд не принимается. Факты, не «вроде работает».
6. Концы строк не менять: код — LF, живой контекст — CRLF. Перед коммитом проверить `git diff --stat` — только файлы из задания.
7. Коммит и пуш — сессия делает сама по приёмке: сообщение `№NNNN: <что, повелительное наклонение>`, прямо в `main`, без веток. Чужие файлы не трогать.
8. Не трогать: `.env`, `data/`, `node_modules/`. Секреты не выводить и не коммитить.
9. Именование задач: `docs/tasks/NNNN-слаг.md`, номер сквозной четырёхзначный, выдаёт штаб. Принятые уходят в `docs/tasks/archive/`.
