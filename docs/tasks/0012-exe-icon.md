# Задача 0012 — иконка exe + видимая ошибка старта

- Проект: MapControl · Статус: открыта · Дата: 2026-09-23

## Цель

Exe выглядит приложением, а не ноунеймом, и не умирает молча: иконка в проводнике и на окне, при фатальной ошибке старта (сервер не найден, порт занят) — системный MessageBox с текстом вместо тихого выхода в никуда.

## Входит

- `desktop/icon.ico` (исходник в git): сгенерировать из простого знака (буквы MC на фирменном синем `#0f2d8a`, см. Sky Pro в `docs/CONTEXT.md`), размеры 16/32/48/256 в одном ICO. Чем рисовать — на выбор сессии (Go stdlib по `knowledge/go-webview-desktop.md` п.18 или готовый конвертер, но без новых runtime-зависимостей приложения).
- `desktop/rsrc_windows_amd64.syso` (в git, собирается через `rsrc -ico icon.ico`): подключить иконку к exe. Тулчейн: `go install github.com/akavel/rsrc@latest` (только инструмент сборки, не зависимость).
- `desktop/main.go`: все `os.Exit(1)` на старте (сервер не найден, порт занят, сервер не поднялся за 30 с) дублировать вызовом MessageBoxW (`user32.dll`, текст ошибки + заголовок из конфига). Консоли по-прежнему нет — окно с ошибкой вместо неё.
- `desktop/README.md`: дописать две строки — установка `rsrc` и полная команда сборки; где должен лежать exe (`desktop/`, рядом с проектом — иначе сервер не найдётся, проверено штабом).
- Проверка иконки в проводнике и текста MessageBox — вручную пользователем (скрин в отчёт не приложить — описать словами, что видно).

## Не входит

- Трей, автообновление, смена имени/версии в свойствах exe. Сервер и фронт не трогать. Второй сайт — отдельный номер 0013.

## Старт (указатели)

- Обёртка: `desktop/main.go` (места `os.Exit`), `desktop/README.md`, знания `D:\GitHub\knowledge\go-webview-desktop.md` п.18 (иконка через rsrc).
- Палитра: `docs/CONTEXT.md` (Sky Pro: `#0f2d8a`, `#5278d6`, `#e06c00`).

## Приёмка

- `gofmt -l desktop/` — пусто; `go vet ./...` — чисто.
- `go build` с новой сборкой — успех, exe показывает иконку (проверка пользователем), размер в отчёт.
- MessageBox проверить живьём: временно переименовать `src/server.js` (вернуть!) → запуск exe → окно с понятной ошибкой, процесс завершается; сервер при этом не висит.
- Дымовой тест как в 0011 (конфиг отдаётся, после закрытия всё гаснет) — повторить, доложить.
- `git status --short`: только `desktop/` + этот файл; `desktop/*.exe` в игноре (уже добавлен штабом) — бинарь в коммит не идёт.
- Коммит `№0012: иконка exe и ошибка старта` + пуш в `main`.

## Ограничения

- `src/`, `public/`, `config/`, `.env`, `data/`, `node_modules/` не трогать. Бинарь не коммитить.
- Стоп и спроси штаба: если rsrc недоступен или WebView2 на машине сборки отсутствует.
