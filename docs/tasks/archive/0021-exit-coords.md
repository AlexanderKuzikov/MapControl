# Задача 0021 — выход в один шаг, очистка координат, долой localStorage

- Проект: MapControl · Статус: на проверке · Дата: 2026-09-25

## Цель

Три ручных замечания к готовому exe: выход мучает двумя диалогами, координаты нечем быстро стереть, а localStorage-кэш бесполезен и только путает (левые координаты при старте). После задачи: выход — один диалог и окно реально закрывается, рядом с координатами кнопка-очистка, localStorage не используется вообще.

## Входит

Frontend (`public/`):
- Кнопка очистки координат (✕) в строке координат: чистит оба поля + снимает маркер через существующий `state.ymap.clearCoords`.
- Выход в один шаг: диалог «Выйти?» → [Выйти] → POST `/api/shutdown` → закрыть окно. В exe — через новый бинд `closeApp` (см. Go); в браузере — как сейчас (`about:blank`), без второго состояния диалога. Двухэкранный «Сервер остановлен / Закрыть окно» убрать.
- Удалить localStorage-fallback целиком: `AUTOSAVE_STORAGE_KEY`, `saveLocalDraft/clearLocalDraft/restoreLocalDraft`, флаг `restoredFromLocal` и его проверки в `initSiteConfig`/`initYandexMap`, сообщение восстановления. Серверный автосейв и статус «Сохранено» остаются. Help-текст проверить на упоминания копии (убрать если есть).

Go (`desktop/main.go`):
- `w.Bind("closeApp", ...)` (только функции — по знаниям): гасит сервер через `killTree` и завершает цикл (флаг + `w.Destroy`? выбрать корректный способ остановки `w.Run`, зафиксировать). Фронт зовёт `window.closeApp()` если есть, иначе старый путь.
