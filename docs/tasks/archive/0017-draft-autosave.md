# Задача 0017 — автосейв черновика (debounce + localStorage)

- Проект: MapControl · Статус: на проверке · Дата: 2026-09-24

## Цель

Оператор не теряет текст при краше браузера, сети или случайном закрытии: форма тихо сохраняется на сервер через 2 с после последней правки, а если сервер недоступен — копия ждёт в localStorage и восстанавливается при следующем открытии. Это P0 из код-ревью (потеря данных оператора).

## Входит

- `public/app.js`:
  - Слушать `input` на полях title/desc/lat/lng: debounce 2 с → тихий сейв (ensureDraft + update без громких сообщений; отдельный маленький статус «Сохранено HH:MM:SS», не затирающий `#msg`).
  - Не запускать автосейв пока идёт проверка (кнопка «Проверить» disabled — идёт `checkLLM`) и пока форма пустая целиком.
  - Fallback: каждый автосейв дублирует текст+координаты в localStorage; при старте страницы, если поля пустые а в localStorage есть копия — восстановить поля + сообщение «Восстановлено из локальной копии».
  - Ошибка сети при автосейве — молча в статус («Не сохранено, попробую позже»), следующий ввод или кнопка «Сохранить» повторяют.
- `public/index.html`: один маленький `<span>` статуса сейва рядом с кнопкой «Сохранить» (id на выбор сессии, зафиксировать в отчёте).
- Фото в localStorage не класть (размер) — только текст+координаты; это ограничение прямо указать в коде комментарием и в отчёте.

## Не входит

- Сервер не трогать (эндпоинта update хватает). Категорию/сваи в автосейв не тащить (живут в apply-llm). Превью, история версий, конфликты копий.

## Старт (указатели)

- Фронт: `public/app.js` (`getForm`, `saveDraft`, `ensureDraft`, `checkLLM`, `wire`, `initSiteConfig`), `public/index.html` (кнопка `btnSaveDraft`).
- Ревью: `CODE_REVIEW_REPORT.md` п. «Draft auto-save (debounce 2s, localStorage fallback)».

## Приёмка

- `node --check public/app.js`.
- Живой сервер: набрать текст → 3 с тишины → `GET draft` отдаёт тот же текст (без нажатия «Сохранить»).
- Сервер потушен: набрать текст → localStorage содержит копию; перезагрузить страницу с пустыми полями → поля восстановились + сообщение.
- Проверка не ломается: во время `checkLLM` автосейв не перезаписывает финальные поля (руками по коду + живой прогон если доступен LLM).
- `git diff --stat`: только `public/app.js`, `public/index.html`. Концы строк как в файлах были. `data/` после тестов чистая (свои черновики удалить, чужие не трогать).
- Коммит `№0017: автосейв черновика` + пуш в `main`.

## Ограничения

- `src/`, `config/`, `.env`, `node_modules/` не трогать. Живые письма и прод-приёмник не дёргать. Тестовые черновики за собой удалять.
- Стоп и спроси штаба: если тихий сейв конфликтует с ручным «Сохранить» или с apply-llm.
