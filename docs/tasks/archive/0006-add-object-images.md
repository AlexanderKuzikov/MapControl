# Задача 0006 — add-object: приём фото из пакета заявки

- Проект: Zavodsvay-Static (задание трекается здесь, в MapControl) · Статус: на проверке · Дата: 2026-09-23

## Цель

Убрать ручное переименование фото: скрипт сам забирает WebP из папки пакета заявки и раскладывает в `assets/img/objects/{id}/` под именами `{id}_1.webp, {id}_2.webp, …`, список имён пишет в поле `images` объекта.

## Входит

- `tools/add-object.mjs`: флаг `--images-from <папка>` (существующая папка с `.webp`). Файлы сортируются по имени, копируются в `assets/img/objects/{id}/` как `{id}_1.webp …` по порядку; поле `images` формируется из этих имён. Существующий флаг `--images` продолжает работать как раньше; передавать оба сразу — ошибка валидации.
- Dry-run: показывает таблицу соответствия `исходник → {id}_N.webp`, ничего не пишет и не копирует. Папка объекта при dry-run не создаётся.
- Пустая папка или отсутствие webp — ошибка валидации, exit 1.

## Не входит

- Формат других полей, страницы, sitemap. Кадрирование и выбор порядка вручную — остаётся за админом (порядок = сортировка имён).

## Старт (указатели)

- Скрипт: `tools/add-object.mjs` (блок изображений, `IMG_DIR`, флаг `--images`).
- Формат пакета заявки: список имён из меты MapControl (файлы уже WebP).

## Приёмка

- Подготовить временную папку с `b.webp, a.webp` (вне репозитория, удалить после): `--dry-run ... --images-from <папка>` — таблица `a.webp → {id}_1.webp, b.webp → {id}_2.webp`, exit 0, папка объекта не создана.
- `--images "x.webp"` вместе с `--images-from` — ошибка валидации, exit 1.
- Несуществующая папка / папка без webp — ошибка валидации, exit 1.
- Реальное копирование в приёмке НЕ делать (только dry-run).
- `git diff --stat`: только `tools/add-object.mjs`. Концы строк как в файле были.
- Коммит `№0006: add-object забирает фото из пакета` + пуш в `main` Zavodsvay-Static.

## Ограничения

- `data/map.json`, `pages/`, `sitemap.xml`, `assets/` не менять (только dry-run). `node_modules/`, `old/`, `.env` не трогать.
- Стоп и спроси штаба: если неясно что считать порядком при нестандартных именах.
