# Задача 0004 — фронт рисует форму из конфига

- Проект: MapControl · Статус: на проверке · Дата: 2026-09-23

## Цель

Форма берёт настройки с сервера вместо хардкода: категории с подписями, центр и зум карты, флаг обязательности свай, имя сайта. Смена `config/site.json` меняет форму без правки фронта.

## Входит

- `public/app.js`: при старте `GET /api/config`, наполнить селект категорий (`value` + `label`), центр/зум карты по умолчанию из `mapCenter`, подпись количества свай по `pileCount.required`, имя сайта в шапке вместо хардкода.
- `public/index.html`: убрать захардкоженные `<option>` категорий (оставить плейсхолдер), убрать захардкоженное имя если есть.
- Деградация: если карты нет (нет ключа) — форма всё равно наполняется; если конфиг не доехал — понятное сообщение вместо пустой формы.

## Не входит

- Поведение карты (клики, маркер, вставка координат) не менять. Логика проверки/отправки не меняется. Стили не трогать.

## Старт (указатели)

- Фронт: `public/app.js` (инициализация, селект категорий, центр карты), `public/index.html` (селект, шапка).
- API готов с 0003: `GET /api/config` отдаёт `siteName`, `categories`, `mapCenter`.
- Конфиг: `config/site.json`.

## Приёмка

- `node --check` на тронутые JS (если правился только фронт — проверка чтением, без сборки).
- Поднять сервер, `GET /app.js` не содержит русских подписей категорий и захардкоженного центра; `GET /` отдаёт селект без захардкоженных опций.
- Живая проверка в браузере если доступен: селект показывает 9 категорий с подписями из конфига; смена `config/site.json` (потом вернуть!) меняет список после перезагрузки. Если браузера нет — зафиксировать в отчёте и проверить чтением кода + curl.
- `git diff --stat`: только файлы из «Входит». Концы строк не поплыли.

## Ограничения

- `.env`, `data/`, `node_modules/`, `config/site.json` (значения) не трогать.
- Стоп и спроси штаба: если что-то из формы не ложится на схему конфига.
