# Задача 0018 — управление фото: дубли, удаление, GPS из любого

- Проект: MapControl · Статус: открыта · Дата: 2026-09-24

## Цель

Оператор видит список загруженных фото и управляет им: повторная заливка того же файла не плодит дубли, любое фото удаляется, координаты можно взять из любого фото с GPS (а не только из первого). Сейчас: залил 1 + 4 (одно повторное) = 5 в заявке, удалить нельзя, GPS только из первого.

## Входит

Backend (`src/server.js`):
- Дедуп по содержимому: `sha256` сырого буфера (node:crypto, без зависимостей); хеш пишется в запись `meta.images[]`; файл с уже имеющимся хешем не сохраняется, в ответе — `duplicates: [<исходные имена>]`. Старые записи без `sha256` считаются уникальными (обратная совместимость).
- GPS для КАЖДОГО файла (сейчас только первый): запись получает `gps: {lat,lng} | null`; поле `gps` ответа — как сейчас, первый найденный (совместимость фронта).
- `DELETE /api/submissions/draft/:id/images/:filename` — удалить файл с диска и запись из меты; имя строго из списка `meta.images` (не с диска), защита путей как везде; в ответе обновлённый список.
- `GET /api/submissions/draft/:id/images/:filename` — отдать webp для превью; файл только из списка `meta.images`, чужой путь → 404/400.

Frontend (`public/app.js`, `public/index.html`, `public/styles.css`):
- Блок списка фото под загрузкой: превью (img через GET выше), имя/порядок, кнопки «✕» (удалить с подтверждением через `confirm`) и «📍» (только при gps у записи — вписать lat/lng в поля + маркер + сообщение).
- Ответ загрузки с `duplicates` — сообщение «пропущено дублей: N» (не ошибка).
- После удаления: список и счётчик обновить, `state.photosUploaded` синхронизировать с новым total (иначе валидация «Проверить» врёт).
- Автоподстановка GPS при заливке — как сейчас (первый найденный, только в пустые поля).

## Не входит

- Пересортировка фото вручную, кадрирование, серверный ресайз превью (оригинальный webp). Поведение submit не менять (он и так берёт только `meta.images`).

## Старт (указатели)

- Загрузка: `src/server.js` (`POST .../images`, sharp, exifr, `sendSubmissionEmail` уже фильтрует по мете).
- Фронт: `public/app.js` (`uploadImages`, `state.photosUploaded`, `validateBeforeCheck`), `config/site.json` не трогать.

## Приёмка

- `node --check` тронутых JS.
- Живой сервер: залить файл дважды → второй раз `duplicates: 1`, в мете 1 запись, на диске 1 файл.

- Фото с GPS вторым по счёту → кнопка «📍» вписывает его координаты.
- Полный цикл в браузере если доступен: выбор → список с превью → удалить → счётчик сошёлся → «Проверить» без дублей.
