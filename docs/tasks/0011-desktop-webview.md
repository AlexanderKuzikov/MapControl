# Задача 0011 — Go+WebView обёртка (окно вместо браузера)

- Проект: MapControl · Статус: на проверке · Дата: 2026-09-23

## Цель

Оператор запускает exe и работает в окне приложения, а не в браузере: Go-программа стартует текущий Node-сервер дочерним процессом, ждёт готовности и показывает его в системном WebView. Поведение сервера и фронта не меняется ни на байт.

## Входит

- `desktop/` — новый каталог: `go.mod` (модуль mapcontrol-desktop, go 1.26, `github.com/webview/webview_go`), `main.go`, README сборки (2–3 строки).
- `main.go`: свободный порт (5179, дальше вверх), запуск `node ../src/server.js` с `PORT` в env, ожидание `GET /api/config` (до 30 с), `Navigate` на `http://localhost:PORT`, заголовок окна из конфига, при закрытии окна — гашение сервера через `taskkill /PID /T /F`.
- Обязательные грабли из знаний (`knowledge/go-webview-desktop.md`, прочитать до кода): сборка с `-H windowsgui`; дочерний console-процесс только с `CREATE_NO_WINDOW` (`0x08000000`); служебных страниц через `SetHtml` нет — только `Navigate` на loopback; бинды JS→Go не нужны вовсе (фронт ходит по HTTP как раньше).

## Не входит

- Иконка exe, трей, автообновление — не сюда (отдельные номера, если понадобятся). Сервер и фронт не трогать вообще. `launcher.js`/`start.vbs` не удалять (старый запуск живёт пока обёртку не примет пользователь).

## Старт (указатели)

- Сервер: `src/server.js` (слушает `PORT`, готовность — `GET /api/config`). Лаунчер: `launcher.js` (логика автопорта — переложить, не копировать вслепую).
- Знания: `D:\GitHub\knowledge\go-webview-desktop.md` — весь раздел «Грабли» обязателен к прочтению.

## Приёмка

- `gofmt -l desktop/` — пусто; `go vet ./...` в `desktop/` — чисто.
- `go build` — честно доложить итог: на Windows нужен CGo + WebView2 SDK, если тулчейна нет — зафиксировать вывод ошибки в отчёт, код всё равно сдаётся.
- Финальный запуск exe и клики по форме — вручную пользователем (в отчёте пометить «приёмка вручную»).
- `git diff --stat` / `git status --short`: только `desktop/` + этот файл. Концы строк: Go-файлы LF.
- Коммит `№0011: Go+WebView обёртка` + пуш в `main`.

## Ограничения

- `src/`, `public/`, `config/`, `.env`, `data/`, `node_modules/` не трогать. Секреты в код и в README не класть.
- Стоп и спроси штаба: если webview_go не собирается в этой среде и непонятно, что с этим делать.
