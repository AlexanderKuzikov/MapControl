# Задача 0015 — drag&drop фото + заливка сразу при выборе

- Проект: MapControl · Статус: на проверке · Дата: 2026-09-24

## Цель

Фото попадают на сервер сразу, а не только внутри «Проверить»: выбор файлов и перетаскивание тут же заливают их и показывают GPS. Оператор видит координаты сразу после загрузки фото — сейчас их не видно, потому что заливка спрятана внутри проверки, а подстановка молчит при заполненных полях.

## Входит

- `public/index.html`: зона вокруг `.file-row` принимает drop (оставить существующий input как есть, добавить `dragover`-подсветку).
- `public/app.js`:
  - `change` на input и `drop` на зону → сложить файлы в input (через `DataTransfer`), обновить подпись, **сразу вызвать `uploadImages()`** (черновик создаётся как сейчас через `ensureDraft`).
  - GPS-ветка: если поля пустые — вписать + маркер (как сейчас); если уже заполнены — показать сообщение с найденными координатами и пометкой «поля уже заполнены, оставлено как было», ничего не затирать.
  - `checkLLM` не ломается: повторная заливка тех же файлов допустима (сервер нумерует по порядку, как сейчас).
- `public/styles.css`: один новый класс подсветки зоны (например `.file-row--over`), в палитре Sky Pro, остальное не трогать.

## Не входит

- Превью-сетка, сортировка, удаление фото, изменения сервера и API. Требование фото в `validateBeforeCheck` не менять.

## Старт (указатели)

- Фронт: `public/app.js` (`uploadImages`, GPS-ветка, `checkLLM`, `wire`), `public/index.html` (`.file-row`), `public/styles.css` (классы файлов).
- Ответ сервера: `POST .../images` → `{ images, gps: { lat, lng } | null }`.

## Приёмка

- `node --check public/app.js`.
- Выбор файла в input без нажатия «Проверить» → запрос на `.../images` ушёл, подпись «Загружено: N», при GPS в ответе — координаты в пустых полях + сообщение.
- Drop файла на зону → то же самое; `dragover` подсвечивает зону.
- GPS при заполненных полях → поля не тронуты, сообщение с координатами видно.
- `git diff --stat`: только `public/app.js`, `public/index.html`, `public/styles.css`. Концы строк как в файлах были (проверить до коммита).
