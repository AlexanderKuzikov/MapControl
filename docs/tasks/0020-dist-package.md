# Задача 0020 — дистрибутив заказчику (папка, а не один exe)

- Проект: MapControl · Статус: открыта · Дата: 2026-09-25

## Цель

Заказчик получает ОДИН файл и работает: текущий exe один недостаточен — ему нужны рядом `src/`, `public/`, `config/`, `node_modules/` (32 МБ), сам Node.js и заполненный `.env`. Настоящий монолит без зависимостей (переписывание сервера на Go) отвергнут штабом: WebP-кодирование без sharp тянет нативную зависимость обратно, а объём — недели с новой поверхностью багов. Вместо этого — самораспаковывающийся архив: один exe, внутри всё нужное. Собрать воспроизводимо скриптом, а не руками.

## Входит

- `desktop/main.go`: искать `node` сначала рядом (локальный portable — `desktop/node/node.exe` и корень проекта), потом в PATH. Без portable не ломать текущий запуск.
- `scripts/make-dist.cjs` (node, без зависимостей): собирает exe (`go build` как в README), складывает `dist/MapControl/` (exe, `src/`, `public/`, `config/site.json`, `package.json` + `node_modules` копией, `.env` из `.env.example` если нет, короткий `ПРОЧТИ.txt` оператора: распаковать, вписать `.env`, запустить). Версия/дата сборки — в имя папки или файл `VERSION.txt` (выбрать, зафиксировать).
- Финал — один файл `MapControl-setup.exe`: SFX (`7z.sfx` из локального 7-Zip + config с `RunProgram`) поверх 7z-архива папки выше. Распаковка во временный каталог, запуск, чистка — средствами SFX. Обычный zip как промежуточный артефакт (не отгружается).
- Portable Node: скачать LTS с nodejs.org в `desktop/node/` (только сам `node.exe` + нужные DLL, без npm; ~30 МБ; в git не коммитить — качается скриптом, в `.gitignore` добавить путь).
- `.gitignore`: `desktop/node/`, `dist/`.

## Не входит

- Установщик/MSI, автопроверка обновлений, подпись бинаря. Секреты в дистрибутив не класть (только `.env.example` как образец).

## Старт (указатели)

- Обёртка: `desktop/main.go` (запуск node), `desktop/README.md`; сервер: `src/server.js` (зависимости — `package.json`); пример настроек: `.env.example`.

## Приёмка

- `gofmt`/`go vet` чисто; `node --check scripts/make-dist.cjs`.
- Свежая сборка в пустую папку → запуск SFX-exe из неё БЕЗ node в PATH (переменная PATH урезана в тесте) → `/api/config` отвечает, черновик создаётся; мусор за собой убрать.
- `git status --short`: только `desktop/main.go`, `scripts/make-dist.cjs`, `.gitignore`, `desktop/README.md` (+ этот файл). Бинари, `node_modules`, `dist/`, `.env` в коммит не идут.
- Коммит `№0020: дистрибутив заказчику` + пуш в `main`.

## Ограничения

- `src/`, `public/`, `config/` содержимым не менять (только упаковка). `npm install` на машине сборки — можно (это явно нужно для дистрибутива), с флагом `--omit=dev`.
- Стоп и спроси штаба: если portable node не заводится или размер дистрибутива неприемлем.
