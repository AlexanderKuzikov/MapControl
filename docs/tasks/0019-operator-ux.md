# Задача 0019 — операторский UX: новая заявка, подсказки, панель фото

- Проект: MapControl · Статус: на проверке · Дата: 2026-09-25

## Цель

Убрать три шероховатости, найденные вручную: при старте в полях лежат старые координаты из локальной копии (непонятно откуда), панель фото без подсказки и мелкая, текст «Подсказок» отстал от новых функций (GPS, drag&drop, дубли, удаление).

## Входит (`public/`)

- Кнопка «Новая заявка» рядом с «Сохранить»: очищает поля, категорию/сваи, список фото и счётчики, `localStorage`-копию, состояние (`submissionId=null`, `llmLast`, `photosUploaded`, `photoImages`), сообщение «Новая заявка». Серверный черновик-сирота остаётся (как после отправки) — так и зафиксировать в отчёте.
- Панель фото: видимая подсказка под зоной («Перетащите фото сюда или нажмите…; JPG/PNG → WebP; GPS подхватится; дубли пропускаются»), зона выше (min-height через существующие классы + один новый при нужде, без редизайна).
- «Подсказки» (help overlay): переписать пункты про фото (drop, дубли, удаление, GPS-кнопка) и координаты (GPS из фото, вставка одной строкой, кнопка GPS у фото, ручной ввод).
- ЖЁСТКОЕ ТРЕБОВАНИЕ БЕЗОПАСНОСТИ (от пользователя, 2026-09-25): координаты из локальной копии НЕ восстанавливать никогда — только текст. При старте поля lat/lng всегда пустые, даже если в копии есть координаты. Чужие координаты в полях = неверный объект на карте = большая ошибка. Сообщение восстановления упоминает только текст («Восстановлен текст из локальной копии»).

## Не входит

- Сервер не трогать. Удаление серверных черновиков-сирот. Смена порядка кнопок и стилей кроме панели фото.
