# MapControl — DECISIONS

## 2026-05-20: LLM для нормализации текста

**Контекст:** Операторы пишут неконсистентные описания объектов.

**Решение:** Qwen 3.5 Flash через OpenAI-compatible API выравнивает текст, определяет категорию, считает сваи.

**Альтернативы:** Ручная модерация, rule-based нормализация.

**Trade-off:** Зависимость от API, но качество выше и быстрее.

## 2026-05-20: Email как транспорт заявок

**Контекст:** Администратор не имеет доступа к серверу.

**Решение:** nodemailer отправляет JSON + фото на email администратора.

**Альтернативы:** Telegram bot, web dashboard, shared folder.

**Trade-off:** Нет трекинга статуса, но zero-infrastructure.

## 2026-09-23: Один сайт — отдельное приложение, не мультитенант

**Контекст:** Инструмент нужен нескольким сайтам, у каждого своя карта и категории.

**Решение:** Один код MapControl, под каждый сайт отдельная установка со своим конфигом. Выбора сайта в рантайме нет.

**Альтернативы:** Мультитенант с переключателем сайта, форк репозитория под сайт.

**Trade-off:** Конфиг выглядит бюрократией пока сайт один, окупается на втором без расходящихся форков.

## 2026-09-23: PHP-приёмник вместо почты и без VDS

**Контекст:** Почта везёт данные и фото, любая смена политики роняет контур; сайт — статика на PHP-хостинге с FTP-деплоем из репозитория.

**Решение:** Очередь заявок — закрытый PHP-приёмник на том же хостинге (приём по токену, approve/reject, скачивание пакета). Публикация остаётся локальной через скрипт статики + деплой. Почта только уведомление. VDS не заводим.

**Альтернативы:** VDS с очередью и админкой, письмо как прежде.

**Trade-off:** Зависимость от лимитов shared-хостинга, но ноль новой инфраструктуры и единый источник правды в git.

## 2026-09-23: Развитие в MapControl, новый репозиторий не заводим

**Контекст:** Куда класть конфиг сайта, приёмник, desktop-обёртку.

**Решение:** Операторское приложение эволюционирует в MapControl. PHP-приёмник и починка публикации живут в Zavodsvay-Static (там их деплой). Go+WebView сначала папкой в MapControl, отдельный репозиторий только когда второй сайт порвёт абстракцию конфига.

**Альтернативы:** Новый чистый репозиторий под универсальный инструмент.

**Trade-off:** Наследуем legacy MapControl, но сохраняем историю, доки и ревью.

## 2026-09-24: Публикация только локально, PHP на проде в map.json не пишет

**Контекст:** Очередь заявок живёт на хостинге, а деплой сайта идёт из git по FTP.

**Решение:** Приёмник на проде — только очередь (приём, approve/reject, скачивание пакета). Публикация — локально у админа: скачанный пакет → `add-object --images-from` → `npm run deploy`. Прямая запись в `map.json` кодом на хостинге запрещена.

**Альтернативы:** Кнопка «опубликовать» в админке приёмника.

**Trade-off:** Лишний ручной шаг админа, но единый источник правды в git и откат деплоем.
